# 阅读与换源功能

按用户提供的作者版本截图，在当前可访问项目源码上实现。作者的私有仓库不可读取，本次实现不依赖其源码。

## 使用入口

- 书源阅读页：轻点屏幕 → 右上角 `…` →「书籍设置」→「换源」。书籍设置和换源页继承应用主题；应用设为跟随系统时随系统明暗切换。
- 换源自动按当前书名和作者查找；同一本书的多个来源可展开选择。换完后仍可通过相同入口再次换源。
- 「阅读设置 → 文字」新增文字亮度（30%–100%）、夜间文字亮度开关、字重（300–700，五档）。开启夜间开关时，深色阅读主题固定使用 70% 文字亮度。
- 「阅读设置 → 主题 → 章节进度」控制左下角的「当前章/总章数」。平板双页时与原页码分行显示。
- 主页面「设置 → 偏好设置 → 悬浮导航栏」可预览并设置尺寸、图标文字、顺序和显示项目，设置入口保留可见。

## 换源时的数据处理

新源的目录与目标章节正文均验证成功后才替换阅读页，准备好的内容直接交给新页面，避免重复请求。失败时原阅读页、书源和进度继续保留。

章节先按标题匹配（忽略章节编号、空格和常见标点）；未匹配时使用原章节序号，并限制到新目录范围。保留章内相对位置，因此不同源正文或目录有差异时可能需要微调。

已加入书架的书更新原记录，不增加重复书架项。原书架 ID、书签和笔记保留；跨源章节锚点尚未重建，目录结构不同可能影响旧书签、笔记的定位。

## 验证与交付状态

覆盖换源失败、分组来源选择、A → B → A、目录标题匹配、书架记录替换，以及正文样式和偏好的持久化。回归范围还包括书源搜索、TXT/EPUB 阅读、滚动/翻页和导航配置。

手机尺寸的书籍设置、文字设置、主题设置和导航配置已用 Flutter 渲染核对。122 项阅读、书源和导航回归通过，主题跟随修正后的 3 项换源测试通过。换源流程覆盖系统深色切换为浅色的主题继承检查。IPA 构建版本为 2.4.8+261002005，交付信息见 XBS_IOS_PREVIEW.zh-CN.md；未进行 iPhone 真机验证。
