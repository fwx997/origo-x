# Origo X XBS iOS 体验版

基于 [miloquinn/origo-x](https://github.com/miloquinn/origo-x) 的个人修改版，保留上游名称、图标、阅读器、字体与 WebDAV。不是上游官方发布版本。修改源码见 [fwx997/origo-x](https://github.com/fwx997/origo-x/tree/feat/xiangse-xbs)。

## 本次交付 2.4.7+261002004

本版打入松鹤及原始书源批量检查中完成的共用引擎修复。安装后请打开设置的关于信息，或书源管理的导入面板，确认显示 **XBS 2.4.7+261002004**（设置中为“XBS 构建”一行）。该标识编译进程序，不依赖安装器提供的版本号。

IPA 内容验收包括单一应用载荷、版本号、程序内构建标识、JSON / XBS 导入文案、打赏资源移除及 ZIP 完整性，并核对新 nativeTool 辅助库与源码一致、依赖许可证已打包。验收报告随包提供。

本轮新增 JSONPath 与 JSON 响应传参兼容、JSON POST、queryInfo 与复合章节 ID、XPath 文本节点／位置／属性判断、源内脚本缓存、MD5、Base64、同步 HTML/XPath 接口及 skipCount/maxPage。Windows 原始 3473 条源检查中，最终 150 条通过相邻两章抽检，其中 116 条此前被过滤，本轮新增确认可读 20 条；这些数字不是所有书籍或所有章节的可用保证。

松鹤已联网验证。言情小说阁、群小说网2仍建议使用另行交付的规则修正版；头文字当前 HTTP 451，番茄系列及七猫等仍有正文接口问题。原始书源、站点凭据和本地审计数据不内置到 IPA。

## 本版功能

上一轮版本：`2.4.5+261002002`（2026-10-02）。搜索、分类、详情和站点选择采用香色式紧凑排版，并优化顶部安全区、字号与大字体间距；修复多图封面地址、晋江 GB18030 编码以及 XPath `@*` / `.` 条件兼容。导入提示统一为 JSON / XBS，移除打赏和首次启动支持引导。

发现、搜索与详情的顶部统一衔接正文主题底色，普通深浅色使用相同字号。本轮另修复书源 GBK 请求编码器初始化异常。本地全量 752 项回归及 10 项 XPath 测试通过，顶部配色调整后追加 42 项页面回归通过；GitHub Actions #5 已通过 746 项 macOS 回归及 XPath 检查，7 项原生脚本测试在 Windows 验证；iOS 编译和 IPA 版本、ARM64、运行库、ZIP、SHA-256 校验均通过。

- 原始 `.xbs` / 香色 JSON 导入，小说源完整保存，不因检测失败删除。
- 独立跨源搜索、书名/作者及精确/包含筛选、同书聚合、详情页查找其他来源。
- 原始分类筛选、分类翻页、失败重试；搜索、发现和管理采用现有主题样式。
- 最多 12 路并发、同站点最多 2 个 HTTP 请求、结果增量显示及取消。
- 书源管理名称/域名筛选、批量搜索或完整阅读链检测。

## 下载与使用

下载 Release 中的 `Origo-X-XBS-2.4.7-261002004-unsigned.ipa`。这是未签名安装包，可按已有 LiveContainer 流程导入，或使用自己的签名工具签名后安装。直接点开 IPA 不会完成 iOS 安装。本版尚未完成实际手机和 LiveContainer 验证。

进入书源管理，导入自己的原始 XBS 文件。先启用少量熟悉的小说源，搜索一本确认存在的书，再检查详情、目录和正文。应用不内置用户原始书源包。

本版使用独立 Bundle ID `com.fwx997.origox.xbs`，显示名称及图标保留上游配置。同步使用现有 WebDAV；不配置原作者的 iCloud 容器，也不承诺 App Store 版本的 iCloud 数据可直接访问。

`SOURCE_COMMIT.txt` 记录构建提交；`SHA256SUMS.txt` 用于校验 IPA。源码中保留上游许可及新增依赖许可。

## 已知限制

- 这是核心功能体验版，未完整兼容香色全部规则。已实现部分 `nativeTool` 计算与缓存接口；WebView、站点登录/Cookie、辅助文件及其他原生接口仍未完成。
- 原文件 185 条小说源可无损保存，不等于 185 个网站均可搜索或阅读。网站离线、验证页和空结果需分别检测。
- “查找其他书源”保留候选来源，尚不支持对已入架书籍自动替换来源并对齐章节进度。
- 书单、联想词、自定义分组/排序、规则编辑/导出、新增 XBS 同步冲突恢复仍在计划中。
- Windows 离线回归、macOS 编译和 IPA 结构校验不能替代 iPhone 实测。

详细实现、验证证据与兼容边界见 [实施记录](https://github.com/fwx997/origo-x/blob/feat/xiangse-xbs/docs/XIANGSE_PROGRESS.zh-CN.md) 和 [行为依据与验收](https://github.com/fwx997/origo-x/blob/feat/xiangse-xbs/docs/XIANGSE_BEHAVIOR_REFERENCE.zh-CN.md)。
