# 香色原包行为依据与本轮验收

日期：2026-10-01。Origo X 分支：`feat/xiangse-xbs`。

## 原始材料与结论

核对的是本地香色闺阁 2.56.1 安装包中提取的资源，以及用户原始 XBS；没有取得完整 Objective-C / Swift 原生源码。

- `book/xsg_extracted/Payload/StandarReader.app/dir_res/plist_settingSearchView.plist`：搜索页面分别配置站点类型和结果过滤。
- 同目录 `plist_settingKeyInfo.plist`：`search_filterResultT` 的 0 为不过滤，2 为匹配关键字，1 为包含关键字（原版推荐默认）。这支持将请求关键词与返回结果过滤分开处理。本项目保留原有不过滤默认值，同时提供精确、包含选项。
- `SearchWebView.js` 是网页内文本高亮、替换和删除脚本，不是跨源搜索调度器，未将其当作搜索引擎源码迁入。
- 原文件 `sourceModelList+3.xbs`：225 条记录，185 条小说；小说中 167 条有发现配置，共 288 个 `bookWorld` 动作。筛选配置为字典 1、字符串 207、数组 48、无筛选 32；解析出 585 个筛选组。
- 字符串形式使用组名与 `标题::值`；数组使用 `key` / `items` / `title` / `value`。实际数组包含整数值，传入脚本时保留数字类型。请求使用 `params.filters.<key>`、`params.filter`、`params.pageIndex`。

`book/_tools/香色闺阁页面结构.md` 只作为已有说明材料，未将其或旧 dudu 代码视为原版源码。实现没有复制原包脚本或品牌资产。

### 紧凑版实施与验证（2026-10-02）

- 发现与搜索使用可搜索名称/host 的站点选择面板，取消不修改范围，确定后沿用原有取消旧请求机制；站内搜索携带当前来源。
- 分类与搜索筛选直接展开，28 高文字选项以主题色标记选中项；站点操作使用 32 高文字按钮，移除大胶囊页签、下拉卡片和多余边框。
- 推荐、分类与搜索采用小封面纵向列表，展示书名、作者、分类/状态、来源、简介和已有最新章节信息；同书来源列表保留全部候选。
- 搜索历史保留最近 20 个关键词，支持点击重搜和清空；书籍详情改为整页，简介和站点信息可滚动，底部加入书架/阅读按钮改为 42 高小圆角。原有加入书架、下载、后台继续和阅读过渡回归通过。
- 修复原始完本神站规则中的 `@*="sortList"` 属性通配比较，以及 XPath 条件中 `.` 当前节点文本解析。保留节点集比较和否定语义，未将未知表达式静默当作成功。
- 晋江实测页面 HTTP 头只有 `text/html`，HTML meta 声明 `gb18030`。响应解码现识别 meta charset/http-equiv，HTTP 中明确支持的编码仍优先，UTF-8 BOM 优先于上述声明。GB18030 四字节生僻字的完整支持仍属既有边界。
- 75 项联合测试通过，包含历史持久化、站点确认/取消、增量搜索与换源、分类取消/分页、详情操作、XPath 及响应解码；修改的应用页面与响应处理静态分析无问题。

## 验收边界

### 2026-10-02 顶部留白、字号与封面跟进

- 搜索顶栏保留输入框上下留白，详情内容距导航栏改为 18；发现标题 24、列表书名 15、详情书名 20。保留紧凑文字筛选与项目主题，预览采用真实首页顶部组件并模拟 47/34 的系统安全区。
- 原预览数据未提供封面 URL，因此只能显示生成的占位封面；已增加图片加载与安全区间距检查。
