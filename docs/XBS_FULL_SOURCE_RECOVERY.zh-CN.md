## 共用修改

- `xbs_runtime.dart`：补充 queryInfo、书名与章节标题，保留数字和 JSON 复合 ID；JSON POST 与请求级响应配置；向 JSParser 传递已解码 JSON；单值 URL 选择；尊重 skipCount、maxPage。
- `xbs_json_path.dart`：递归路径、数组索引、存在判断、字面值比较过滤，拒绝任意 JS 过滤执行。
- XPath：属性存在与否、count、position/last、包含自身的相对列表字段、带空格谓词、文本节点及序号、引号内分隔符；避免 text() 把正文挤成一行后被清理正则整段删除。
- `xbs_rule_engine.dart`：兼容 XBS 的未加引号通配属性、单／双竖线 @replace 清理链。
- `xbs_javascript.dart` 与 `tool/xbs_helpers/`：实现同步日志、源内缓存、MD5、Unicode Base64 和 HTML/XPath 包装接口。纯计算依赖固定版本、锁文件与许可证随包保存；未开放网络、文件、Cookie 或设备原生能力。缓存限制为 32 源，每源 128 项／256 KiB，正文节点、脚本内存与执行时间继续设限。

## 验证与限制

通过列表只表示 Windows 真实 FJS / HTTP 中同一本书的相邻两章抽样通过：每章至少 200 字符、100 汉字，无替换乱码、无已知验证提示，内容不同。对新增源查看了标题和正文摘录，发现导航项、跨章过量分页后追加修复和复测。这不保证目录完整、所有书籍或全部章节可读，未验证登录、付费内容或手机端。

最终全量回归 767 项通过，1 项既有章节缓存写入测试在并行负载下等待超时；该测试文件单独重跑 9 项全部通过。40 项 XBS/XPath 针对测试通过。修改的 XBS 与测试文件经 `dart analyze --format=machine` 无诊断；vendored XPath 包保留原有的发布配置／风格提示。Flutter LSP 分析在此中文路径环境发生消息解析异常，使用 Dart machine 分析完成验证。

本地原始检查点与实验脚本在 Git 忽略目录 `.dart_tool/source-audit/`。报告导出不包含书源中的 Cookie／Token 或整章正文；导入包保留用户原始配置，仅用于本地交付。
